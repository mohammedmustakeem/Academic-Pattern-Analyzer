# Academic Pattern Analyzer

## Overview

Academic Pattern Analyzer is a machine learning project designed to study student exam performance patterns using academic score data. The system analyzes mathematics, reading, writing, and total scores to identify performance trends between male and female students.

---

## Features

### Data Preprocessing
Cleaning and preparing the dataset for analysis.

### Feature Engineering
Creation of a new feature, `total_score`, by combining mathematics, reading, and writing scores.

### Performance Analysis
Identifying trends and patterns in student performance based on examination scores.

### Logistic Regression Model
Applying Logistic Regression for classification and prediction tasks.

### Feature Scaling
Standardizing numerical features using `StandardScaler` before model training.

## Machine Learning Workflow

### 1. Dataset Collection
The dataset is sourced from Kaggle.

### 2. Data Preprocessing
The data is cleaned and organized for analysis.

### 3. Feature Engineering
A new feature, `total_score`, is generated using existing subject scores.

### 4. Train-Test Split
The dataset is divided into training and testing sets.

### 5. Feature Scaling
Numerical features are standardized using `StandardScaler`.

### 6. Model Training
A Logistic Regression model is trained on the processed dataset.

### 7. Prediction and Evaluation
Predictions are generated and evaluated using classification metrics.

## Dataset

**Students Performance in Exams Dataset**

The dataset contains information related to student academic performance, including:

- Gender
- Parental Level of Education
- Lunch Type
- Test Preparation Course
- Mathematics Score
- Reading Score
- Writing Score
